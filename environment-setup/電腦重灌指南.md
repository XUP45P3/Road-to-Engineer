# 💻 電腦重灌指南 (Windows 11 家用版)

- **系統版本**：Windows 11 家用版
- **準備工具**：USB 隨身碟 (至少 8GB)、備用電腦、外接硬碟 (備份資料用)

---

## 階段一：準備安裝檔案

1. **下載 Windows 11 ISO 檔**
   - 前往 [Microsoft 官網](https://www.microsoft.com/zh-tw/software-download/windows11)
   - 找到 **下載適用於 x64 裝置的 Windows 11 磁碟映像 (ISO)**
   - 選擇 `Windows 11（適用於 x64 裝置的多版本 ISO）` ➔ 點擊 **立即下載**
   - 選擇語言 `繁體中文` ➔ 點擊 **64位元 下載**

2. **下載 Rufus 燒錄工具**
   - 前往 [Rufus 官網](https://rufus.ie/zh_TW/)
   - 在 **最新版本** 區塊，下載 `rufus-4.xx.exe 標準版`

---

## 階段二：製作開機隨身碟

> ⚠️ **注意**：接下來的步驟會將 USB 格式化，請確保裡面沒有重要資料！

1. 將 USB 插入電腦，雙擊執行 `rufus-4.xx.exe`。
2. 在介面中進行以下設定（未提及的選項保持預設即可）：
   - **裝置**：選擇你插入的 USB
   - **開機模式**：`磁碟或 ISO 映像檔` ➔ 點擊 **選擇** 載入剛下載的 ISO 檔
   - **磁碟分割配置**：`GPT`
   - **目前系統**：`UEFI (無 CSM)`
   - **檔案系統**：`NTFS`
3. 點擊最下方的 **執行** 後，會跳出客製化選單，推薦勾選以下項目：
   - [x] 移除對 4GB+ 記憶體、安全開機和 TPM2.0 的要求 *(老電腦必勾)*
   - [x] 將登入微軟帳號的要求移除
   - [x] 使用此使用者名建立一個本機帳戶：`(輸入你的名字)`
   - [x] 關閉資料收集 *(跳過隱私設定)*
4. 點擊 **確認** ➔ **OK**，等待進度條跑完，開機隨身碟就完成了！

---

## 階段三：BIOS 設定與系統安裝

> 🚨 **最終確認**：請確保電腦上的**一切重要檔案**都已備份！

1. **進入 BIOS**：USB 保持插在電腦上，點擊 **重新啟動**。在螢幕亮起前，持續點擊 `F2`（或 `Delete`、`F12` 等按鍵）進入 BIOS 畫面。
2. **設定開機順位**：找到 `Boot` (開機) 選項，將 **USB 隨身碟** 調整至第一順位。
3. **儲存並重啟**：按下 `F10` 儲存設定並退出。
4. **開始安裝**：電腦重啟後會自動讀取 USB，進入 Windows 安裝畫面，接著跟隨畫面指示操作即可。

---

## 階段四：系統更新與基本軟體安裝

1. **更新 Windows**
   > 💡 有些硬體驅動程式必須透過系統更新之後才會抓到並安裝。
   - 打開系統 **設定**
   - 在左側邊欄點擊 **Windows Update**
   - 點擊右側的 **檢查更新**，並等待所有更新下載安裝完成。

2. **安裝 Office (透過 Office Tool Plus)**
   > 📺 詳細操作可參考影片：[Office LTSC 安裝教學](https://youtu.be/gSlr6sH7cd0?si=g7pzPFbXvwiyQ5vY)

   **A. 下載與執行**
   - 進入 [Office Tool Plus 官網](https://otp.landian.vip/zh-tw/)
   - 點擊 **立即下載**
   - 選擇 **64位元** 並下載 `7z 壓縮包版本（文件更小）`
   - 下載後解壓縮 `Office_Tool_with_runtime_v11.5.7.0_x64.7z`，並雙擊執行 **Office Tool Plus.exe**

   **B. 部署 Office**
   - 在左側選單進入 **部署** 區塊。
   - **產品** 區塊：點擊 **新增產品**，選擇 `Office LTSC 專業增強版 2024 (大量授權)`。 *(⚠️：一定要有「大量授權」字樣)*
   - **語言套件** 區塊：點擊 **新增套件 (L)**，選擇 `繁體中文 (台灣)`。
   - 選擇要安裝的 **應用程式** (例如：Excel, Word, PowerPoint 等)。
   - 在右側的 **部署 Office** 區塊確認設定：
     - 部屬模式：`安裝`
     - 架構：`64 位元`
     - 更新通道：`Office 2024 永久企業版`
     - 安裝模組：`Office 部署工具`
   - 確認完畢後，點擊最上方的 **開始部署 (D)**。

   **C. KMS 啟用破解**
   - 安裝完畢後，先隨意打開 Word 或 Excel，點擊左下角的 **帳戶**，此時應顯示 **未啟動**。
   - 關閉 Office 軟體，進入 [KMS 主機列表](https://monitor.yerong.org/kms/)，隨意複製前三名的其中一個 **KMS 主機代碼**。
   - 回到 Office Tool Plus，在左側選單進入 **啟用** 區塊。
   - 找到 **KMS 管理**，點選向下箭頭，貼上剛剛複製的 KMS 主機代碼。
   - 依序點擊 `設定主機 (S)` ➔ `啟用 (A)` [03:50]。
   - 看到 **產品啟用成功** 的提示後，再次打開 Word/Excel 查看帳戶狀態，顯示 **產品已啟用** 即代表破解成功！
