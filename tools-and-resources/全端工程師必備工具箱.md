# 🚀 全端工程師 工具箱

### 前端資源 (Frontend)

- 🖌️ **設計靈感與配色**
  - [Recent](https://recent.design/websites)：參考矽谷工程師的頂尖網站設計
  - [Coolors](https://coolors.co/)：超好用的網頁設計配色生成器

- 🧩 **UI 介面與元件**
  - [Stitch](https://stitch.withgoogle.com/)：由 Google 推出的 AI 網頁介面生成工具
  - [Shadcn](https://ui.shadcn.com/)：質感極佳且可高度客製化的 UI 元件庫

---

### 後端與資料庫 (Backend & Database)

- 🗄️ **資料庫管理**
  - [Aiven](https://aiven.io/)：專業的雲端純資料庫代管服務
  - [MySQL Workbench](https://www.mysql.com/products/workbench/)：老牌強大的 MySQL 官方視覺化管理工具
  - [Supabase](https://supabase.com/)：極受歡迎的開源全端解決方案 (Firebase 完美替代品)

- 🌐 **部署與測試**
  - [Vercel](https://vercel.com/)：現代網頁架設與一鍵部署平台 (Next.js 首選)
  - [Postman](https://www.postman.com/)：後端 API 開發與測試的必備神器

---

## 🤖 AI 與進階工具 (AI & DevOps)

- 🧠 **AI 模型與框架**
  - [Nvidia NIM](https://developer.nvidia.com/nim)：Nvidia 推出的 AI 推論微服務
  - [Ollama](https://ollama.com/)：讓你輕鬆在本地端跑起各種強大 LLM
  - [AI SDK](https://sdk.vercel.ai/)：Vercel 專為構建 AI 網頁應用打造的開發包

- 🐳 **基礎設施與版控**
  - [Docker](https://www.docker.com/)：讓環境部署不再踩坑的軟體容器化技術
  - [Git](https://git-scm.com/)：工程師必備的版本控制核心
  - [Fork](https://git-fork.com/)：介面美觀又流暢的 Git 視覺化軟體
